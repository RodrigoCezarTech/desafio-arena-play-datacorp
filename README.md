# 🏅 ArenaPlay Sports — DataCorp Simulator

Projeto prático desenvolvido durante uma simulação de Análise de Dados, Scrum e desenvolvimento Java com SQL.

## 🎯 Sobre o projeto

A simulação representa o ambiente de uma empresa fictícia do mercado esportivo, envolvendo gestão de atletas, análise de dados e operações em banco de dados.

## 🚀 Etapas desenvolvidas

- Briefing e planejamento com metodologia Scrum.
- Limpeza e organização de dados.
- Análise de KPIs e geração de insights.
- Consultas SQL para análise de atletas.
- Desenvolvimento de operações CRUD com Java e JDBC.
- Elaboração de relatório executivo.

## 🛠️ Tecnologias e conceitos

- Java
- SQL
- JDBC
- MySQL
- PreparedStatement
- ResultSet
- Programação Orientada a Objetos (POO)
- Scrum
- Análise de Dados
